# Active Curriculum

The active hierarchy is:

```
Book
  → Chapters
      → Lessons
          → Questions
```

The project contains one primary book: **Build Spring PetClinic from Zero to Final**.

The legacy 1,150-question set is preserved under `archive/original-question-baseline/` and must not be silently substituted for the active curriculum. Questions are rewritten into teaching-first wording and grouped into lessons before becoming active.
